# MovieChooser

Aplicativo desktop Windows que recomenda filmes e séries/animes disponíveis em plataformas de streaming.

## Requisitos

- Node.js 18.19+

## Stack

- Electron
- React
- TypeScript
- Vite

## Scripts

```bash
npm install
npm run electron:dev
npm run typecheck
npm run lint
npm run build
```
